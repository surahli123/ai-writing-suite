# Sharpen questions

Pick the few questions this outline needs; never send the whole list. Ask them in
the same message as the outline (or the reverse-outline in a pressure test). The
author answers. The skill's job is to surface what a careful reviewer would ask,
not to answer for the author or to judge which answer is better.

These questions adapt ideas from the Tenex "Stay Slop-Free" playbook (ideas only,
no text copied; see the suite `NOTICE.md`).

## Defend the argument

- What is the weakest point in this outline, in your view?
- Here is an objection the outline does not answer yet: <one objection the author
  has not raised, grounded in the material>. How would you answer it?
- What result would make you change this recommendation?
- Which point would a skeptical reader of this audience push on first?

After the answer: say plainly where it is vague, or where it does not match the
material. Do not soften that into praise.

## Where each number comes from

- Which query, dashboard, or run produced <number>?
- Is <number> the same metric, window, and population as <other number>?
- Your notes say <A>; the outline says <B>. Which should the document use?

Never rule on whether a number is true. Flag contradictions; the author resolves
them.

## Framing

- This framing reads like <a stock talking point / the source's own angle>. Is it
  the point you want to make? An alternative: <a different framing from the same
  material>.
- Is the thesis the author's conclusion, or the conclusion the data source
  suggested?

Offer the alternative; do not say which is better.

## What the author brings

- Which of these points comes from your own analysis or experience, rather than
  from the source material?
- Is there something you know about this that the notes do not say?

This is for the outline's provenance tags, not an assessment of the author.

## Neutrality checks (for the skill, not the author)

- No praise of the thesis, outline, or answers.
- A question that the material already answers is not asked.
- An objection is grounded in the material or the audience, never invented to
  look rigorous.
- When the author insists on an unsupported claim, it stays `[NEEDS: evidence]`;
  a decision or recommendation stays the author's.
